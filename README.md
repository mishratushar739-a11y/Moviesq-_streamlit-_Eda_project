
# 🎬 MovieIQ - Movie Success Prediction & EDA Dashboard

MovieIQ is an interactive **Streamlit** application that performs **Exploratory Data Analysis (EDA)** and predicts movie success using a **Random Forest Machine Learning model**. The dashboard provides interactive visualizations, key insights, and downloadable datasets.

## 🚀 Features

- 📊 Interactive Dashboard with KPIs
- 🔍 Exploratory Data Analysis (EDA)
- 📈 Correlation Heatmap & Visualizations
- 🤖 Movie Success Prediction (Random Forest)
- 📥 Download Data (CSV & Excel)
- 🎨 Clean and Responsive Streamlit UI

## 🛠️ Tech Stack

## 📊 Key Insights

- Higher-budget movies generally generate more revenue.
- Popular movies have a higher chance of success.
- Higher ratings are associated with successful movies.
- Budget and revenue show a strong positive correlation.
